# Octofit Tracker Frontend

## Overview
The Octofit Tracker frontend is built using React and Vite. This application serves as the user interface for the Octofit Tracker fitness app, allowing users to log activities, manage profiles, and interact with various features of the app.

## Project Structure
The project is organized as follows:

```
octofit-tracker
└── frontend
    ├── public
    │   └── robots.txt
    ├── src
    │   ├── components
    │   │   └── index.jsx
    │   ├── pages
    │   │   └── Home.jsx
    │   ├── App.jsx
    │   ├── main.jsx
    │   └── index.css
    ├── .gitignore
    ├── index.html

```

## Setup Instructions

1. **Clone the Repository**
   ```bash
   git clone https://github.com/apyd/skills-build-applications-w-copilot-agent-mode.git
   cd skills-build-applications-w-copilot-agent-mode/octofit-tracker/frontend
   ```

2. **Install Dependencies**
   Make sure you have Node.js installed. Then run:
   ```bash
   npm install
   ```

3. **Run the Development Server**
   Start the development server with:
   ```bash
   npm run dev
   ```

4. **Open the Application**
   Open your browser and navigate to `http://localhost:3000` to view the application.

## Features
- User authentication and profiles
- Activity logging and tracking
- Team creation and management
- Competitive leaderboard
- Personalized workout suggestions
